# 🎓 Capstone Management System

A web-based platform for managing Capstone projects, tracking student team progress, assigning reviewing engineers, and managing capstone milestones.

---

## 🚀 Recent Platform Updates (v1.2.0)

### 📊 Teams Overview & Team Profile
- **Engineer Filtering**: Filter teams by assigned engineer or easily find teams with no engineers assigned.
- **Visual Progress Tracking**: Real-time task completion progress bars on team cards.
- **Staff Indicators**: Engineer names displayed directly on team cards for fast scanability.
- **Interactive Team Profile Editing**: Authorized users can edit project identity, bilingual names, and scope descriptions with auto-expanding text fields and live title updates.

### 📈 Teams Progress & Student Tasks
- **Weekly Completion Benchmarks**: Dynamic progress bars for each academic week tracking overall team milestone completion.
- **Drag-and-Drop Staff Assignment**: Real-time drag-and-drop interface for assigning engineers and reviewers in Capstone Management / Super Admin.
- **Team Roster Integration**: "My Project" tab features a roster detailing Team Members (with leader badges), Assigned Engineers, and Capstone Supervisors.
- **Team Leader Resolution Fix**: Complete submission tracking visibility for both Team Leaders and members.

> For full detailed release notes, see [CHANGELOG.md](./CHANGELOG.md).
